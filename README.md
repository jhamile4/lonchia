# LonchIA: asistente inteligente para loncheras sin desperdicio

Proyecto del curso **Sociedad Sostenible** de Diseño y Desarrollo de Software, TECSUP, Lima, 2026-I.

**ODS 12: Producción y consumo responsables · Meta 12.3**

LonchIA es una app móvil para padres, madres y tutores de estudiantes de primaria. Sirve para registrar los alimentos de casa (con la boleta y OCR, con el código de barras o a mano), recibir alertas antes de que algo venza y obtener recetas de loncheras con IA, empezando por lo que vence primero.

## Contenido

La demo está en [`lonchia_demo/`](lonchia_demo/). El OCR, el código de barras y la IA están simulados con datos de ejemplo.

## Ejecutar la demo

```bash
cd lonchia_demo
flutter pub get
flutter run -d chrome
```
